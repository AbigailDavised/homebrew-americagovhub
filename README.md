# Homebrew Tap for americagovhub-cli (americagovhub.com)

Official Homebrew tap for **[americagovhub.com](https://americagovhub.com)** command-line tools.

## Installation

```bash
brew tap AbigailDavised/americagovhub
brew install americagovhub-cli
```

## Quick Test

```bash
americagovhub-cli --help
```

# AmericaGovHub — US Federal Benefits Eligibility & USCIS Civics Exam Engine

Provides automated Federal Poverty Level (100% to 400% FPL) benefit screening across SNAP, Medicaid, and Lifeline, paired with the official USCIS 100 Civics naturalization exam test bank.
